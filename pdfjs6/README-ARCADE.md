# PDF.js v6.2.108 — official Mozilla viewer, CUSTOMIZED for Arcade Hub

This is the **latest official release** of Mozilla's PDF.js
(v6.2.108, from https://github.com/mozilla/pdf.js/releases), customized for
Arcade Hub. Rebuilt by `tools/build_pdfjs6.py` (it downloads the official
dist zip itself and applies every change below — re-run it to reproduce
byte-for-byte). License: Apache 2.0 (`LICENSE`, CMaps © Adobe).

## IMPORTANT: why `engine/` and `.js` (not `build/` and `.mjs`)

- The workspace/snapshot system treats directories named `build`, `dist`,
  `out`, `target` as disposable build artifacts and DELETES them between
  sessions — which silently broke the viewer twice. Hence **`engine/`**.
- Some static hosts/proxies mis-serve `.mjs` with a non-JS MIME type, which
  hard-blocks module scripts. Hence **`.js`** names (`engine/pdf.js`,
  `engine/pdf.worker.js`, `web/viewer.js`). GitHub Pages serves `.js`
  correctly everywhere.

## Modifications (documented per Apache-2.0 §4(b))

### 1. `web/viewer.html`
- **The entire right side of the toolbar was removed** (`#toolbarViewerRight`):
  highlight, comment, free-text, draw/ink, image/stamp and signature editors
  (plus their parameter popups), **print**, **save/download**, and the whole
  **Tools menu** (secondary toolbar with rotate, spreads, presentation mode,
  cursors, document properties, open-file, alt-text settings).
  What remains: views manager (thumbnails/outline/attachments/layers),
  find, page navigation, zoom.
- Page title → "Arcade Hub — PDF Viewer".
- Loads `arcade-hub.js` before the viewer modules; script URLs point to
  `../engine/pdf.js` and `viewer.js`.

### 2. `web/arcade-hub.js` (NEW — our customization layer)
Removing toolbar HTML alone crashes the stock `viewer.js` (it binds
listeners to those elements with no null checks). This layer makes
`document.getElementById()` return an invisible detached placeholder for the
82 removed ids, so the viewer runs perfectly with a clean toolbar.
It also rewrites a parameter-less URL to `?file=arcade-demo.pdf`.

### 3. `web/viewer.js` (renamed from `viewer.mjs` — 3 strings + 1 function changed)
- `workerSrc`: `"../build/pdf.worker.mjs"` → `"../engine/pdf.worker.js"`
- `sandboxBundleSrc`: `"../build/pdf.sandbox.mjs"` → `"../engine/pdf.sandbox.js"`
- `defaultUrl`: `"compressed.tracemonkey-pldi-09.pdf"` → `"arcade-demo.pdf"`
  (our demo PDF is the default document; Mozilla's sample PDF was removed).
- `onBeforeUnload()` → never calls `preventDefault()`. The stock handler showed
  the browser's "Leave site? Changes you made may not be saved" dialog when the
  annotation storage was touched — from inside the viewer iframe that can block
  navigation of the whole Arcade Hub page. All editing tools are removed from
  this build anyway, so the protection is pointless here.

### 4. `web/arcade-demo.pdf` (NEW)
Generated by `tools/make_demo_pdf.js` — 13-page branded test document with a
`NEEDLE` search target on page 7.

### Not modified
`engine/pdf.js` + `engine/pdf.worker.js` (byte-identical to the official
`pdf.mjs`/`pdf.worker.mjs`), `viewer.css`, `images/`, `locale/` (112 languages
incl. `hi-IN`), `cmaps/`, `standard_fonts/`, `iccs/`, `wasm/`.

## Browser support & fallback
v6 requires a modern browser (~Chrome 111+ / 2023+) because it uses ES
modules. `js/pdf-embed.js` feature-detects, serves this viewer to modern
browsers on http(s), and automatically falls back to the v3.11.174 viewer in
`/pdfjs/` for old browsers and `file://` contexts (where modules are
CORS-blocked). A 9-second watchdog re-opens the same PDF in v3 if this
viewer fails to boot for any reason.
